# 📦 Blockchain in Java with JavaFX GUI

A simple blockchain implementation written in **Java** with a **JavaFX-based graphical interface**, based on the concepts from the book *"Introducing Blockchain with Java"*.  
This project demonstrates blockchain concepts — from creating blocks to verifying transactions and mining — in an interactive, user-friendly way.

---

## 🚀 Features
- 📜 **Block structure** with hash, previous hash, timestamp, and transactions
- 🔑 **Digital signatures** for secure transactions using public/private key cryptography
- ⛏ **Proof-of-Work** mining algorithm
- 🔗 **Blockchain validation** to ensure data integrity
- 💼 **Wallets** for creating and signing transactions
- 📝 **Transaction ledger** display
- 🎨 **JavaFX GUI** for interacting with the blockchain visually

## 📥 Installation & Run

### 1️⃣ Clone the repository
```bash
git clone https://github.com/username/blockchain-javafx.git
cd blockchain-javafx
```

### 2️⃣ Import libraries manually
- Download dependencies:
    - Base64 
    - JavaFX SDK
    - SQLite jdbc
- Place them into the libs/ folder 
- Add them to your project’s classpath in your IDE (IntelliJ IDEA / Eclipse)

### 3️⃣ Run the application
From the terminal:
```bash
javac --module-path lib/javafx-sdk/lib --add-modules javafx.controls,javafx.fxml -cp "lib/*" src/gui/MainApp.java
java  --module-path lib/javafx-sdk/lib --add-modules javafx.controls,javafx.fxml -cp "lib/*:src" gui.MainApp
```
Or simply run MainApp.java from your IDE with VM options:
```bash
--module-path /home/dadry/Projects/NullCoin/NullCoin/libs/runtime --add-modules javafx.controls,javafx.fxml
```

## 💻 GUI Overview

The JavaFX interface includes:
- Transaction Form — Create and sign transactions between wallets 
- Blockchain Viewer — View mined blocks with their hashes and transactions 
- Mining Control — Start mining new blocks from the UI 
- Validation Status — See if the blockchain is valid

## 🔄 Blockchain Workflow (simplified)

```plaintext
[Transaction Created in GUI] --> [Transaction Signed with Private Key]
          |
          v
[Transaction Added to Block] --> [Mining via Proof-of-Work]
          |
          v
[Block Added to Blockchain] --> [Validation in Real-Time]
```
